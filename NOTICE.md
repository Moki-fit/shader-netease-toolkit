# Third-party notice

This repository does not bundle third-party shader projects, tutorial pages,
cached shader source, course text, images, or author assets. It stores no API
key and does not grant any right to redistribute material obtained through a
supported provider.

## Source-specific boundaries

- **Shadertoy:** the optional legacy integration uses only the official Public +
  API surface. Preserve the project URL/ID, author, stated license and required
  Shadertoy API attribution. A missing explicit license is not permission to
  redistribute a work.
- **ISF:** automatic indexing is limited to the upstream Vidvox `ISF-Files`
  standard library. Preserve its MIT license text and upstream copyright notice.
- **twigl.app:** the platform/program license does not license individual user
  works. A resolved `ol=true&ss=<id>` share link may use one bounded request to
  the fixed experimental Firebase snapshot endpoint only with a caller-stated
  `user-owned`, `licensed`, or `author-permission` basis. `reference-only` and
  `repository-license` remain zero-network link/metadata records. Never
  enumerate channels or directories; the individual work license remains
  unknown until separately evidenced.
- **ShaderFrog:** its editor link is a work-specific reference and supports
  only user-supplied-source analysis, never automatic project fetching. Obtain
  authority and review the individual work license before caching, copying,
  adapting or distributing source.
- **Godot Shaders:** `reference-only` and `repository-license` may examine only
  the canonical individual page and retain page evidence/metadata; they must not
  call the shader-detail endpoint or make a final reusable-source classification
  before a source header is checked. Only `user-owned`, `licensed`, or
  `author-permission` with one supported, unambiguous CC0/MIT/GPLv3 license
  scoped to the target article may call the matching fixed detail endpoint.
  Caching additionally requires exactly one matching supported license in the
  leading source header. A missing, restrictive, composite, or conflicting
  header blocks caching and remains `review_required`.
  Do not crawl project directories or media.
- **The Book of Shaders:** chapters, including `?lan=ch` Chinese pages, are
  reference-only links. Its offline seed may store only the toolkit's original
  topic links, never chapter page content; the toolkit does not cache or
  redistribute that content.
- **WebGL Fundamentals:** automatic indexing is confined to eligible official
  lesson Markdown under the upstream BSD-3-Clause course repository. Retain the
  BSD-3-Clause notice; exclude third-party folders, images and assets.

Unknown, absent or conflicting license information must be preserved as
`unknown` / review-required, not upgraded to reusable content. Import only
content that you are authorized to disclose to the connected Codex/MCP client,
and keep import/export files outside this repository.
