# Shadertoy to NetEase Toolkit plugin

This plugin bundles the `port-shadertoy-to-netease` Skill and the
`shadertoy-netease` local stdio MCP server. See the repository-level README for
installation, API-key handling, attribution, and verification instructions.

The MCP starts from the plugin root with Node 24 and has no third-party runtime
dependencies. It does not include a cached shader database or any API key.
